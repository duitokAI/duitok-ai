# Duitok Agent 状态卡视觉优化 PRD

## 1. 背景

当前 Agent 左侧状态卡在完成态下已经能表达“任务完成”，但截图中视觉体验很奇怪：

- 顶部标题显示 `Completed`，图内左上角也显示 `Completed`，信息重复。
- 图内右上角仍显示 `待命中`，和外部完成态互相冲突。
- 3D 场景被放在一个很大的白色框里，下半部分空白过多，像图片没有加载完整。
- 图片、状态 badge、说明文字都在争抢注意力，用户不知道应该看“已完成”、看图，还是看底部英文说明。
- 当前语言是中文环境，但底部仍出现英文提示 `The last task is complete...`，语言不统一。

这个问题不是单纯的图片尺寸问题，而是“状态信息架构 + 视觉容器比例 + 文案语言”同时失衡。

## 2. 目标

把 Agent 左侧状态卡从“重复状态海报”优化成“清晰的任务状态面板”。

核心目标：

- 用户 1 秒内知道 Agent 当前状态：已完成 / 待命中 / 工作中 / 需要确认。
- 3D 场景完整展示，不被裁切，也不出现大片无意义空白。
- 完成态只保留一个主状态表达，避免同一屏出现多个互相冲突的状态。
- 文案跟随当前语言，不再中英混杂。
- 左侧状态卡和右侧聊天窗口在首屏视觉重量平衡。

## 3. 非目标

- 不重做 Agent 后端工作流。
- 不改 Agent 消息发送、确认、扣 credits 或工具调用逻辑。
- 不更换 3D/图片素材。
- 不恢复已删除的 `Workspace Summary` 和 `Tell Me What To Do` 卡片。
- 不把左侧做成营销 hero，本期只优化工作台状态卡。

## 4. 当前问题诊断

### 4.1 状态重复且冲突

截图中同时出现：

- 外层标题：`Completed`
- 图内左上 badge：`Completed`
- 图内右上 badge：`待命中`
- 底部文案：`The last task is complete...`

问题：

- 用户会困惑：Agent 现在到底是已完成，还是待命中？
- `Completed` 出现两次，显得像 debug 状态重复渲染。
- 完成后回到待命是合理逻辑，但视觉上不应该同时用两个同级 badge 表达。

### 4.2 图片容器比例不对

当前图片上半部分有内容，下半部分大面积白底，给人感觉：

- 图被“吃掉”或没有铺满。
- 卡片高度被硬撑大。
- 视觉重心偏上，下半部分空洞。

实际原因可能是：

- 图片使用 `contain` 后完整显示，但容器高度大于素材有效视觉区域。
- 3D 场景素材自身底部留白较多，前端又额外给了固定高度。
- 卡片容器没有按图片实际视觉比例约束。

### 4.3 完成态不需要大场景

完成态用户最关心的是：

- 任务已经完成。
- 下一步可以继续发指令。

大场景图适合待命/工作中展示，但完成态不需要占据过高空间。完成态应更像“完成回执 + Agent 回到待命”的状态，而不是一张巨大海报。

### 4.4 文案语言不统一

当前页面是中文环境，侧边栏和顶栏都是中文，但状态卡底部是英文：

```text
The last task is complete. You can ask me for the next step.
```

问题：

- 破坏 Studio 内部工具的专业感。
- 用户会觉得 Agent 页面没有完全本地化。

## 5. 设计原则

### 5.1 一个状态只说一次

每个状态卡只能有一个主状态 badge。

完成态推荐：

- 主标题：`已完成`
- 副文案：`上一轮任务已完成。你可以继续让我安排下一步。`

图内不再叠加 `Completed` / `待命中` 这种重复 badge。

### 5.2 图片是状态背景，不是信息主体

3D 场景负责传达“Agent 在工作台里”，但不承担主要文案任务。

要求：

- 场景完整可见。
- 不能裁切关键物体：桌子、聊天台、床、Agent。
- 不能出现超过图片容器 25% 的纯空白区域。
- 不在图片内部重复渲染和外层冲突的状态标签。

### 5.3 完成态轻量化

完成态应该比工作中状态更安静：

- 不需要进度轨道。
- 不需要多个 badge。
- 不需要过大的图片高度。
- 可以保留一张小型场景图作为状态确认。

### 5.4 跟随当前语言

所有状态文案必须走 `agentUiCopy()` 或同等 i18n 来源。

中文环境：

- `已完成`
- `上一轮任务已完成。你可以继续让我安排下一步。`

英文环境：

- `Completed`
- `The last task is complete. You can ask me for the next step.`

马来文环境：

- `Selesai`
- `Task tadi sudah selesai. Anda boleh minta langkah seterusnya.`

## 6. 推荐方案

### 6.1 状态卡结构

Desktop 左侧状态卡改成：

```text
+------------------------------------+
| ✓ 已完成                            |
| 上一轮任务已完成。你可以继续安排下一步。 |
|                                    |
| [完整 3D 场景图，16:10 或 4:3]       |
+------------------------------------+
```

说明：

- 状态标题和说明放在图片外部。
- 图片内部不显示重复状态 badge。
- 完成态标题使用当前语言。
- 图片区域高度固定在合理范围，不跟随聊天区撑满。

### 6.2 图片容器比例

建议桌面端：

- 左栏宽度：`minmax(420px, 0.82fr)`
- 图片容器高度：`320px-360px`
- 图片展示方式：`object-fit: contain`
- 容器背景：白色或极浅紫白渐变
- 圆角：`14px-16px`

建议移动端：

- 图片容器高度：`240px-280px`
- 左侧状态卡不 sticky，按页面自然流排序。
- 不让图片超过首屏 45% 高度。

### 6.3 状态 badge 规则

外层状态 badge：

- idle：`待命中`
- busy：`工作中`
- confirm：`需要确认`
- done：`已完成`

图片内部 badge：

- 默认隐藏。
- 如果后续要保留，只能显示和外层一致的状态。
- 完成态禁止同时出现 `已完成` 和 `待命中`。

### 6.4 完成态文案

中文推荐：

```text
上一轮任务已完成。你可以继续让我安排下一步。
```

更短版本：

```text
已完成。你可以继续发下一步指令。
```

英文仅在英文语言环境显示。

### 6.5 工作中状态差异

工作中状态可以比完成态更动态：

- 显示 `正在理解你的需求`
- 显示轻量进度：`理解需求 · 检查资料 · 准备执行`
- 可以保留小气泡，但必须避免遮挡图片关键主体。

完成态不显示进度，只显示结果。

## 7. 功能需求

### 7.1 前端结构

要求：

- `agentStatusCard()` 只输出一个主状态标题。
- `agent3DScene()` 支持 `compact` 或 `statusCard` 模式。
- 在 `statusCard` 模式下隐藏 `.agent-3d-status` 或至少隐藏图内重复 badge。
- 状态说明使用 `agentStatusInfo().hint`，并确保跟随语言。

验收：

- 完成态截图里只出现一次主要 `已完成`。
- 不出现图内 `Completed` + `待命中` 同屏冲突。

### 7.2 CSS 布局

要求：

- `.agent-life-render-image` 使用 `object-fit: contain`。
- 不使用 `transform: scale(...)` 放大图片。
- `.agent-life-stage` 桌面高度控制在 `320px-360px`。
- 状态卡不被强行撑到和聊天卡一样高。
- 图片底部空白不超过容器高度 25%。

验收：

- 桌面 1280px 宽度下，床、桌子、中间聊天台都完整可见。
- 没有图片被裁切的感觉。
- 没有大面积空白占据左侧状态卡下半部分。

### 7.3 多语言

要求：

- 状态标题、状态说明、完成文案全部从 `agentUiCopy()` 获取。
- 不在 JSX/模板字符串中硬编码英文完成提示。

验收：

- 中文环境不出现 `The last task is complete...`。
- 英文环境仍显示英文。
- 马来文环境显示马来文。

### 7.4 响应式

要求：

- `>1180px`：左右双栏，左侧状态卡宽度 420px 以上。
- `900px-1180px`：左侧宽度可降到 380px，但图片仍完整。
- `<900px`：单列布局，状态卡在聊天卡上方。
- `<640px`：图片高度降低，输入框保持可见。

验收：

- 1280px、1024px、390px 三个宽度无文字重叠。
- 图片不被裁切。
- 顶栏按钮不挤压标题。

## 8. 视觉验收标准

### P0

- 完成态只出现一个主状态表达。
- 中文环境不出现英文完成提示。
- 3D 图片完整显示，不裁切关键主体。
- 已删除的 `Workspace Summary` 和 `Tell Me What To Do` 不恢复。

### P1

- 左侧状态卡高度自然，不出现大块空白。
- 图片内部 badge 不遮挡床、桌子或 Agent。
- 左右两栏视觉重量平衡，聊天区仍是主要工作区。

### P2

- 状态切换时无明显布局跳动。
- 完成态、待命态、工作中状态都能复用同一套容器规则。

## 9. 建议实施顺序

1. 调整 `agent3DScene()`：为状态卡模式隐藏内部状态 badge。
2. 调整 `agentStatusCard()`：状态标题 + 状态说明前置，图片只做视觉辅助。
3. 调整 CSS：固定图片容器合理高度，`contain` 显示，取消放大。
4. 检查 i18n：完成态文案全部走 `agentUiCopy()`。
5. 用 1280px、1024px、390px 截图验收。
6. 跑 `npm run build`。

## 10. 风险与注意事项

- 如果完全隐藏图内 badge，工作中状态可能少一点“正在动”的感觉，需要通过外层状态和 thinking card 补足。
- 如果图片容器太矮，场景会变小；如果太高，又会出现空白。建议先用 `336px` 作为桌面基准，再按截图微调。
- 由于当前素材本身带大量白底，不能只靠 `contain`，还需要控制容器高度。
- 不要为了铺满而恢复 `cover`，否则又会出现“图被吃掉”的问题。
